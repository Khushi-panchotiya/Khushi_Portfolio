# Project cover images

Cover images for the 3 featured projects. Save them here with names that match
the `cover` field in `../../js/content.js`:

| File                 | Used by                          |
|----------------------|----------------------------------|
| `project-one.png`    | Featured card + detail page 1    |
| `project-two.png`    | Featured card + detail page 2    |
| `project-three.png`  | Featured card + detail page 3    |

Recommended: 16:10 landscape, ~1600px wide, JPG/PNG/WebP under ~400 KB.

If a file is missing, the featured card shows a coloured gradient tile with the
project name, and the detail page simply hides the cover image — the site still
looks fine.

To add or rename: change the `slug` / `cover` in `js/content.js`, rename the
matching `projects/<slug>.html` page, and drop the image here.
