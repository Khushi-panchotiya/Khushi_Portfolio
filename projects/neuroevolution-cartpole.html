GitHub repo

What it is

An interactive web app that demonstrates Neuroevolution — Evolutionary Strategies — solving the classic CartPole-v1 control problem from OpenAI Gymnasium. Built with Grishma Makwana.

Why I built it

To make a black-box optimization method tangible: you watch the agent learn to balance the pole in real time and see how each hyperparameter changes that.

How it works

  • A population of neural-network weight vectors is generated and perturbed with random noise.
  • Each agent is scored by how long it keeps the pole balanced.
  • Base weights are nudged toward the highest-performing mutations — the Evolutionary Strategies update.
  • Streamlit UI with live reward graphs and on-the-fly control of population size, mutation strength, and learning rate.

What I learned

How gradient-free optimization can train a policy without backprop, and how population size and mutation strength trade off exploration against stable convergence.
