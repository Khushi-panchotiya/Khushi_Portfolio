What it is

My first end-to-end machine learning project: predicting which passengers survived the Titanic from the classic Kaggle dataset. The goal was less about the leaderboard and more about walking the full pipeline once, carefully, on my own.

Why I built it

I wanted to move past tutorials and actually own every step — from raw CSV to a trained, evaluated model — so I could see where accuracy really comes from.

How it works

  • Full pipeline: EDA → cleaning → feature engineering → modeling → evaluation.
  • Engineered features that carried most of the signal: Title, FamilySize, IsWomanOrChild, RichWoman.
  • Handled missing values and categorical encoding before modeling.
  • XGBoost tuned with GridSearchCV, reaching 82.12% accuracy.

What I learned

Feature engineering moved the needle far more than model choice. I also got comfortable with the mechanics of cross-validated hyperparameter search and reading a full ML pipeline end to end.
