Feedforward Neural Network from Scratch

PythonNumPyDeep LearningBackprop
GitHub repo

What it is

A feedforward neural network built entirely from first principles in NumPy — no autograd, no high-level frameworks — to demonstrate a working understanding of the maths underneath modern deep learning.

Why I built it

Libraries like PyTorch and scikit-learn hide how a model actually learns. I wanted to close the gap between using a network and understanding one by deriving and coding every step myself.

How it works

  • Manual forward pass: linear layers with ReLU hidden activations and a softmax output.
  • Cross-entropy loss paired with softmax, with gradients derived by hand via the chain rule.
  • Backpropagation and a from-scratch SGD optimizer, then extended with momentum.
  • Trained on the Breast Cancer Wisconsin dataset (569 samples, 30 features) and benchmarked against scikit-learn's MLPClassifier on an identical split.

What I learned

Where the accuracy gap against a library model really comes from — weight initialization, optimizer sophistication (Adam vs. plain SGD), and regularization — and why momentum measurably speeds up convergence.
